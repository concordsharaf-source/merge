# حسابي | Hesabi

**حسابي** هو تطبيق ويب عربي قابل للتثبيت (PWA) لإدارة المتجر محليًا: المنتجات والمخزون والمبيعات والفواتير والمشتريات والمرتجعات والعملاء والموردون والدفعات والصندوق والتقارير. تظل بيانات العمل في **IndexedDB** على الجهاز، مع خيار نسخ سحابي يدوي مجاني عبر Firebase للأدمن فقط.

## ما الذي يغطيه الإصدار الأول؟

| المجال | ما يتوفر الآن |
|---|---|
| الإعداد | اسم المتجر، النشاط، والعملة في أول تشغيل فقط؛ والافتراضي هو الريال اليمني (`YER` / `ر.ي`) |
| المنتجات | إضافة، بحث بالاسم أو الباركود أو الكود الداخلي، تعديل، حذف ناعم، ومنع تكرار الباركود |
| ماسح الباركود | زر مسح داخل نموذج المنتج يستخدم كاميرا خلفية و`BarcodeDetector` عند الدعم، مع إدخال يدوي آمن عند عدم الدعم |
| المخزون | كمية افتتاحية، حالات متوفر/منخفض/نافد، وحركة تعديل موثقة |
| المبيعات | سلة، منع المخزون السالب، نقدي أو تحويل، خصم، ومبلغ مدفوع |
| الفواتير | أرقام `INV-000001` متسلسلة، تفاصيل محفوظة، وخصم مخزون ذري |
| PWA | Manifest وعامل خدمة للتشغيل بعد أول تحميل دون اتصال |
| النسخ السحابي | رفع واستعادة يدويان عبر Firebase Authentication وCloud Firestore، مع آخر 3 نسخ وبصمة SHA-256 ونسخة وقائية محلية |

## التقنيات

التطبيق مبني بملفات واجهة الويب القياسية: **HTML5 وCSS3 وJavaScript ES Modules**. يستخدم Vite للبناء وIndexedDB لجميع بيانات العمل المحاسبية وجلسة التطبيق المحلية. يستخدم Firebase Web SDK فقط لخيار النسخ اليدوي: بريد/كلمة مرور منفصلان للنسخ وCloud Firestore مقيد بقواعد مالك النسخة. لا يعتمد التطبيق على Firebase Storage أو أي خدمة مدفوعة.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

لإنتاج نسخة بناء قابلة للنشر:

```bash
pnpm build
```

ولتشغيل الاختبارات المنطقية:

```bash
pnpm test
```

## الاستخدام

عند أول فتح، أدخل اسم المتجر ونشاطه والعملة ثم اضغط **دخول**؛ ويكون الريال اليمني (`ر.ي`) مختارًا تلقائيًا ما لم تغيّره. عند إضافة منتج، تستطيع إدخال الباركود يدويًا أو الضغط على **مسح** لفتح الكاميرا الخلفية في متصفح يدعم `BarcodeDetector`. يتوقف المسح بعد أول قراءة، ويملأ الحقل تلقائيًا، ويمنع التطبيق حفظ الرمز إذا كان مرتبطًا بمنتج آخر. بعد ذلك، أضف الكمية الافتتاحية، وعدّل الكميات من شاشة **المخزون** فقط. من **المبيعات** أضف المنتجات إلى السلة، ثم أدخل الخصم والمبلغ المدفوع وحدد وسيلة الدفع وأكد العملية. ينشئ التطبيق فاتورة وحركات بيع ويخصم الكميات ضمن معاملة IndexedDB واحدة قدر الإمكان.

### النسخ السحابي اليدوي

بعد دخول **الأدمن**، افتح **الإعدادات** ثم اختر **ربط النسخ السحابية**. أنشئ حساب Firebase بالبريد وكلمة مرور مخصصين للنسخ أو سجّل الدخول إلى حساب نسخ موجود. اختر **إنشاء نسخة سحابية الآن** عند الرغبة في حفظ وضع الجهاز الحالي. من جهاز آخر، سجّل الدخول إلى التطبيق محليًا، ثم إلى **نفس حساب النسخ السحابي**، واختر النسخة ثم **استعادة**. ستنزل حسابي نسخة JSON وقائية قبل الاستبدال، وتتحقق من الأجزاء والبصمة، ثم تعيدك إلى شاشة الدخول المحلية. هذا ليس نظام مزامنة لحظية ولا يدمج تعديلات جهازين.

## تثبيت التطبيق

افتح التطبيق من متصفح حديث. بعد أول تحميل، اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية** من قائمة المتصفح. يستخدم التطبيق `manifest.json` و`service-worker.js`، وتُخزن ملفات واجهته الأساسية في التخزين المؤقت للاستخدام دون اتصال.

## الهيكل

```text
client/
  index.html
  public/
    manifest.json
    service-worker.js
  src/
    main.js
    style.css
    js/
      app.js          # العرض والتفاعلات
      constants.js    # الخيارات الثابتة
      database.js     # IndexedDB والمعاملات الذرية
      domain.js       # منطق المخزون والفواتير
tests/
  domain.test.mjs
```

## نشر GitHub Pages

يوجد إعداد GitHub Actions في المستودع الأم لنشر نسخة `web-pwa` تلقائيًا. فعّل GitHub Pages من **Settings → Pages** واختر **GitHub Actions** كمصدر للنشر. عند الدفع إلى فرع `master` بعد تعديل ملفات التطبيق، ستنشئ المهمة نسخة الإنتاج وتنشرها.

## حدود النسخ السحابي

تقتصر الحصة التطبيقية على ثلاث نسخ مكتملة لكل حساب نسخ، وتوجد حماية حجم 12 MiB للنسخة قبل Base64. لا تستخدم هذه الميزة Firebase Storage، ولا تعمل دون اتصال، ولا تستبدل النسخ المحلية JSON. لا تضغط «استعادة» إلا عندما تكون متأكدًا أن النسخة المختارة تمثل البيانات التي تريدها على هذا الجهاز.
